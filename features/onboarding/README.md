# Onboarding

`OnboardingFeature.mount` owns the onboarding routes, splash, advanced options and recovery screens. It creates or restores the default wallets through `provisioning` and records the verified physical backup in the RecoverBull backup facts of the restored network. The host supplies those capabilities, language access, the logo (both the create/recover logo and, optionally, the loading mark), the background image, and the navigation that follows a ready wallet.

## Loading splash

While a wallet is being created or restored, the route shows the "black camo" splash: a full-page graphite texture with the Bull Bitcoin mark refilled in a staggered cascade. The create/recover screen keeps its previous red grid look, so only the backdrop and the logo differ between the two states.

- `OnboardingFeature.mount` takes `logo` and an optional `loadingLogo`. `loadingLogo` is what the loading page renders and defaults to the V3 `SplashMark`; the host passes both so the same affordance (the tap-to-unlock superuser gesture) wraps each one. `SplashMark` is published by `package:onboarding/onboarding.dart`.
- `assets/splash/bb-mark-{tl,tr,bl,br}.svg` — the four shapes of the Bull Bitcoin mark, one file per shape, each keeping the source `viewBox="0 0 2975 2512"` and the source `d` value verbatim. This package is the canonical home of the artwork: no build step and no tool reads another workspace to produce it. The files carry no fill — `SplashMark` paints them with the theme's `AppColors.markFixed` — and the Android vectors `res/drawable/splash_mark.xml` and `splash_mark_android12.xml` repeat the same four `d` values, scaled to the launch-screen sizes.
- `assets/splash/splash_camo.png` — the 512 × 512 opaque graphite camo texture (SHA-256 `2b9f0cc54bf9a9814ea74073d3d20551ca39441e5c96ff45d6d64511d8626440`). It is a derivative of the app icon already in this repository, `assets/logos/icon-black-red.png` (512 × 512 RGBA, SHA-256 `91f186ad90a63a49a701472cfcc12fa9bf79c7d304b5f713b69568e5e039af5d`): the icon's **static red bull** is masked out (source pixels whose red channel leads green by ≥ 12, dilated by 2 px) and that area is rebuilt from the icon's own logo-free 20 px tiles, with one per-channel mean correction per tile and a feathered ramp where tiles overlap. Every pixel outside the mask is copied through byte-for-byte, the output is fully opaque, and its maximum red-minus-green lead is 8, so no red survives. The rebuilt area is a reconstruction from the icon's texture rather than the original pixels under the mark, which is why no red may be painted back into it. The texture is drawn with `BoxFit.cover`, is never stretched or tiled, and the same bytes ship as `android/app/src/main/res/drawable-nodpi/splash_camo.png` for the pre-Android 12 launch screen, where `res/drawable/splash_camo_cover.xml` draws it through `CoverBitmapDrawable` with the same `BoxFit.cover` geometry over a `#15171C` base; a byte-equality test keeps the two copies identical.
- `SplashMark` runs one 950 ms linear cycle, each shape delayed by 50 ms, and starts at 35 % of the cycle so the first frame matches the fully filled native launch screen instead of blinking an empty page. `disableAnimations`/`reduceMotion` stop the ticker and show the static mark. The mark is decorative: it is excluded from the semantics tree, and the loading copy carries the message for screen readers.

To change the mark, edit the four SVG `d` values and mirror them in the two Android drawables; `test/ui/splash_mark_geometry_test.dart` fails while the copies disagree. `test/ui/splash_mark_test.dart` covers the timings, reduced motion, disposal, semantics and asset decoding. Neither test uses golden images, and neither reads from a design workspace or any path outside this repository.

## Dependencies

- `mnemonic_entry` supplies typed recovery input with explicit language selection; `wallet_import` supplies the read-only Bitcoin history scan. `bull_recoverbull` supplies public recovery navigation and the wallet backup facts. `provisioning` creates or restores the default wallet pair.
- `settings` supplies the machine translation warning shown after a language change.
